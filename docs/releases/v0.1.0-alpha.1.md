# Agent Bridge v0.1.0-alpha.1

First experimental Go-only prerelease. Agent Bridge synchronizes explicitly
registered local Claude Code and Codex resources. This is a bounded configuration
bridge, not full feature parity, behavioral equivalence, or a production safety
guarantee. Start with disposable fixtures and review every adopted resource.

## Included

- Shared instruction sections, portable skill directories and optional strict
  common skill metadata.
- Selected stdio/HTTP MCP configuration and portable skill-only plugin packages.
- Minimal custom agents and bounded startup-hook configuration.
- Bidirectional reconciliation, conflict/deletion protection, private transaction
  journals, recovery, read-only audit and global/project onboarding.
- Stable-input polling, optional multi-profile coordination and opt-in macOS
  background service install/start/stop/status/uninstall.
- Version reporting and standalone Go binaries; MIT license.

## Downloads

Choose `darwin` for macOS or `linux`, then your CPU architecture: `arm64` for
Apple Silicon/ARM64, `amd64` for Intel/AMD x86-64. Four `.tar.gz` archives and
`SHA256SUMS` accompany this prerelease. Each archive contains the binary, README
and license. Go is needed to build from source, not to run a downloaded binary.

Compare the archive's SHA-256 digest with its line in `SHA256SUMS`, extract into a
new empty directory, and run `./agent-bridge --version`. See the
[distribution guide](https://github.com/Jhorlin/agent-bridge/blob/v0.1.0-alpha.1/docs/distribution.md)
and [onboarding guide](https://github.com/Jhorlin/agent-bridge/blob/v0.1.0-alpha.1/docs/onboarding.md).
The binaries are unsigned and not notarized. Checksums detect corruption but are
not signatures or independent proof of provenance.

## Validation and limits

Validation includes Go race tests, vet/build checks, parser/adapter fuzzing,
macOS/Linux CI, all four cross-builds, archive/checksum/header tests, and native
architecture version-command smoke tests. Isolated host fixtures used Claude Code
2.1.266 and Codex CLI 0.153.4 on macOS 26.4.1. Native startup tests use loopback
fake providers; no real-model behavior or paid calls are represented as tested.
Release archives are built with Go 1.25.4, with cgo disabled.

Not included: OAuth/token synchronization, host permissions/trust, universal
skill invocation semantics, arbitrary hooks, rich agents, bundled plugin MCP,
automatic native plugin installation/cache refresh, automatic resource enrollment,
Windows support, or a Linux service installer. Unsupported translation fields
fail explicitly; raw-copy resources still require human portability review.

External editor races and partial multi-file visibility remain. Power-loss,
login/reboot, every host version, and arbitrary script behavior are not certified.
Do not use this alpha for security-sensitive production configuration. Downloading
or running `--version` does not install anything or enroll real host settings.

See the [compatibility matrix](https://github.com/Jhorlin/agent-bridge/blob/v0.1.0-alpha.1/docs/compatibility.md)
and [readiness record](https://github.com/Jhorlin/agent-bridge/blob/v0.1.0-alpha.1/docs/release-readiness.md)
for the exact supported subset and test evidence.
